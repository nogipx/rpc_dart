# RPC-11 — Пакет вне workspace

Пути:       packages/transport/rpc_dart_wasm/lib/**, packages/core/rpc_dart_generator/lib/**
Применима:  в репозитории есть пакеты вне pub workspace
Применена:  —

Уточняет:    U-03

Форма:       `rpc_dart_wasm` и `rpc_dart_generator` не участвуют в общем прогоне,
             поэтому обычный гейт их не видит.
Детектор:    список участников workspace против списка каталогов в `packages/`.
Спрашивать:  этот пакет резолвит ядро из локального исходника или из
             опубликованного?
Ломается:    неверный результат: гейт зелёный при сломанном пакете, потому что
             проверена опубликованная версия ядра, а не та, что вот-вот уедет.
Улика:       без `pubspec_overrides.yaml` wasm-цель молча тестирует ОПУБЛИКОВАННОЕ
             ядро.
Статус:     подтверждена (раунд 186, вне журнала)
