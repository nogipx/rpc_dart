# RPC-10 — Общий слой достаёт не всех соседей

Пути:       packages/core/rpc_dart/lib/**, packages/transport/rpc_dart_websocket/lib/**, packages/transport/rpc_dart_http2/lib/**, packages/transport/rpc_dart_isolate/lib/**, packages/transport/rpc_dart_http/lib/**
Применима:  несколько транспортов делят части одного слоя
Применена:  —

Уточняет:    U-11

Форма:       фикс в общем слое кажется покрывающим все транспорты, а часть из них
             использует только его половину.
Детектор:    карта «какой транспорт использует какой слой»: `RpcChannelTransport`
             общий для канальных, но `RpcFrameMultiplexedChannel` — НЕ для isolate.
Спрашивать:  какие пакеты РЕАЛЬНО проходят через изменённый класс?
Ломается:    неверный результат: заявление о радиусе фикса, не подтверждённое
             кодом. Дважды попадало в сообщения коммитов, а через них — в
             решение не проверять соседа.
Улика:       радиус был переоценён в двух коммитах подряд.
Статус:     подтверждена (раунд 150, вне журнала)
