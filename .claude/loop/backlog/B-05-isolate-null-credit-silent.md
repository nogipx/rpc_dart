# B-05 — isolate: молчаливый сбой оконного кредита

Нулевой кредит читается как «пир не участвует» — это намеренный путь деградации
для старого пира. Поэтому потеря гранта неотличима от старого пира, и сбой
молчаливый.

Измерено: окно соединения 8 KiB, попотоковое выключено, инертный воркер →
200/200 чанков уходило до фикса, 8/200 после.

Связанная ловушка: `BufferedBroadcastController` НЕ закрывает окно до готовности —
его сброс идёт синхронно изнутри `listen()`, то есть из конструктора канала, в
контроллер, на который транспорт ещё не подписан; кадры теряются хопом позже.
Ранняя подписка закрывает окно на обоих хопах.
