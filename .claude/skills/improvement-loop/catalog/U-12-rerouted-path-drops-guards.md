# U-12 — Перенаправленный путь теряет стражей старого

Пакет:       core
Форма:       вызов A заменён вызовом B, а A проверял то, чего B не проверяет.
Детектор:    грепать замены помощников, чьё имя кодирует предусловие
             (`...IfNeeded`, `...Once`, `ensure...`, `tryX`), на более простых
             собратьев.
Спрашивать:  что проверял A и не проверяет B?
Ломается:    двойное действие, нарушенный инвариант.
Применима:   везде, где есть идемпотентные обёртки над обычными операциями.
Улика:       замена помощника со стражем дала порядок, при котором уходили два
             терминальных сообщения там, где везде уходит одно.
Статус:      подтверждена
