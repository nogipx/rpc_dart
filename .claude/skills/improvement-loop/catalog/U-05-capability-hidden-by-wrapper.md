# U-05 — Возможность, спрятанная обёрткой

## Форма

Поведение включается проверкой `is IFoo`, а объект приходит
завёрнутым в декоратор, который интерфейс не пробрасывает.

## Детектор

Грепать проверки типа и приведения по интерфейсам-возможностям; для
каждой пройти цепочку обёрток от места создания до места проверки.

## Спрашивать

Доживает ли интерфейс до проверки через все обёртки на пути?

## Улика

200 из 200 потоков прошли против потолка 3: потолок работал,
проверка возможности — нет.
