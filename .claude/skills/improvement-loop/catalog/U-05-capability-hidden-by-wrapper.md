# U-05 — Возможность, спрятанная обёрткой

Пакет:       core
Форма:       поведение включается проверкой `is IFoo`, а объект приходит
             завёрнутым в декоратор, который интерфейс не пробрасывает.
Детектор:    грепать проверки типа и приведения по интерфейсам-возможностям; для
             каждой пройти цепочку обёрток от места создания до места проверки.
Спрашивать:  доживает ли интерфейс до проверки через все обёртки на пути?
Ломается:    молчаливое отключение защиты — худший вид, потому что тесты зелёные.
Применима:   есть декораторы, прокси, адаптеры вокруг основного типа.
Улика:       200 из 200 потоков прошли против потолка 3: потолок работал,
             проверка возможности — нет.
Статус:      подтверждена
