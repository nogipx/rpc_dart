# U-08 — Лимит счастливого пути на пути ошибки

Пакет:       async-io
Форма:       одна граница применяется и к данным, которые сейчас разберут, и к
             диагностике о том, почему разбирать нечего.
Детектор:    места, где путь ошибки читает или собирает данные тем же кодом, что
             и успешный путь.
Спрашивать:  для чего эта граница? Ограничивать декодируемое тело и ограничивать
             строку объяснения — разные задачи.
Ломается:    потеря информации, неверный класс ошибки: повторяемая становится
             неповторяемой.
Применима:   есть лимиты на размер входных данных.
Улика:       код ошибки от чужой стороны подменялся собственной жалобой на размер
             страницы, которая его несла, хотя статус был известен ДО чтения.
Статус:      подтверждена
