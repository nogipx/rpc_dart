# U-19 — Матрица паритета

Пакет:       core
Форма:       комбинация «форма x реализация x направление», на которую никто не
             написал теста.
Детектор:    построить список всех осей и отметить покрытые комбинации.
Спрашивать:  какая комбинация пуста и почему именно она?
Ломается:    что угодно.
Применима:   есть больше одной оси вариативности.
Улика:       дыры живут ровно в комбинациях, а не в отдельных значениях осей.
Статус:      подтверждена
