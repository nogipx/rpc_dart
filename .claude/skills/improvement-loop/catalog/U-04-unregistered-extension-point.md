# U-04 — Незарегистрированная точка расширения зависимости

Пакет:       core
Форма:       зависимость предоставляет колбэк или сеттер, обёртка его не ставит.
Детектор:    перечислить публичное API зависимости на колбэки, сеттеры и
             `on*`-поля; для каждого найти место регистрации в своём коде.
Спрашивать:  какое событие мы из-за этого не узнаём никогда?
Ломается:    зависание, течь, потеря данных.
Применима:   есть обёртка над чужой библиотекой.
Улика:       единственный способ узнать об обрыве со стороны пира не был подписан
             никем — отменённый вызов работал вечно.
Статус:      подтверждена

В собственном коде ничего не выглядит неправильным: **дефект имеет форму
пустоты.**
