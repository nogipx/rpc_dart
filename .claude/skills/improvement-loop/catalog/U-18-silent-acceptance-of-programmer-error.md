# U-18 — Тихое приятие ошибки программиста

Пакет:       core
Форма:       запись в map, затирающая прежнее значение; несоответствие, которое
             никто не отвергает; идентификатор, выданный дважды.
Детектор:    присваивания в разделяемые коллекции без проверки существования;
             выдача идентификаторов, переживающая перезапуск компонента.
Спрашивать:  что происходит, когда два разных объекта претендуют на один ключ?
Ломается:    потеря данных, действие над не тем объектом.
Применима:   везде.
Улика:       идентификаторы, начинающиеся заново после переподключения, дали
             очистку мёртвой операции, закрывающую наполовину ЖИВУЮ; оба очевидных
             фикса не сработали.
Статус:      подтверждена
