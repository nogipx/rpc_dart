RPC Dart

Transport-agnostic RPC framework for Dart. Write a contract once and run it in process, over HTTP/2 with the real gRPC wire, HTTP/1.1, WebSocket, isolates or a WebAssembly bridge. Unary and all three streaming shapes, deadlines, cancellation, flow control and resource limits included.

pub.dev API reference GitHub Issues

Install

dart pub add rpc_dart

Start with the rpc_dart README. Each transport package's README covers its own setup.

Using an AI coding agent

rpc_dart ships an Agent Skill: verified reference material for contracts, endpoints, streaming, errors, limits and testing, matched to the version you depend on. Install it into your project: 

dart run skills@ get

It goes into .claude/skills/, .agents/skills/ or your agent's equivalent. On an SDK without dart run <package>@, add skills as a dev dependency and run dart run skills get. See the skills CLI.
